## 프로젝트 소개
- 서비스 : SEONWON — 3D 그래픽, 2D 일러스트, AI 영상 포트폴리오
- 사용자 : 작업물을 보러 온 사람 (채용 담당자, 협업 제안자, 동료 창작자)
- 목적 : 어떤 작업을 하는 사람인지 빠르게 파악하고 연락한다
- 핵심 행동 : 관심 분야 작업물 보기 → 마음에 든 작업으로 문의 남기기

## 이번 과제에서 추가한 기능
- 작업 모달의 '이 작업으로 문의하기' 버튼을 추가하여, 작업물을 보다가 바로 Contact 문의 흐름(1~4단계)을 시작할 수 있다.
- 누른 작업의 분야에 맞춰 문의 유형(작업 문의)과 관심 분야를 채우고, 어떤 작업으로 문의 중인지 표시함.
- 연결 지점 : 기존 문의 흐름의 앞(진입 경로)에 연결했다.

## 사용자 흐름
- 진입 경로 : Contact 섹션으로 들어갈 때 
                - 기존 : 메뉴의 Contact(또는 스크롤) 로 섹션에 도착.> 빈 공란인 1단계에서 직접 입력.
                - 추가 : 작업을 선택하여 모달 아래의 ' 이 작업으로 문의하기' 클릭 > Contact 섹션 1단계로 이동 >
                        > 문의 유형, 관심분야가 미리 채워져 작업이 연결됨.
- 완료 조건 : 3단계에서 제출하면 4단계 완료 화면이 표시된다. (이 사이트는 메일을 보내지 않고 완료 화면만 보여준다)
    1. 문의 유형 : 문의 유형, 관심 분야
    2. 연락 정보 : 이름, 이메일, 메시지
    3. 내용 확인 : 입력 내용 요약(연결된 작업 포함), 항목별 수정, 제출
    4. 완료 : 완료 문구 표시

## 인터렉션 시나리오
- 행동 > 조건 > 반응 > 다음 상태
    * 다음 클릭     > click  > 필수 입력 통과   > 다음 단계 표시, 진행 문구 갱신         > step + 1
    * 다음 클릭     > click  > 필수 입력 누락   > 이동을 막고 오류 안내, 해당 칸에 focus > step 유지
    * 이전 클릭     > click  > 항상           > 이전 단계 표시, 입력값은 그대로         > step - 1
    * 수정 클릭     > click  > 3단계에서      > 해당 단계로 이동                        > step = 1 또는 2
    * 제출 클릭     > submit > 3단계에서      > 완료 화면 표시                          > isComplete = true
    * 새 문의 작성  > click  > 4단계에서      > 입력·선택·오류·진행 상태 초기화          > step = 1

    * 문의하기 클릭 > click > 항상 > 모달 닫힘, 문의 유형·관심 분야 채움, 연결 표시줄 표시, 1단계로 이동 > relatedWork = 그 작업, step = 1
    * 문의하기 클릭 > click > 이미 같은 작업과 연결됨 > 다시 채우지 않고 '이미 연결되어 있습니다' 안내, 보던 단계·입력값 유지 > 상태 유지
    * 문의하기 클릭 > click > 이미 완료된 문의 > 이전 문의를 초기화하고 새로 시작 > isComplete = false, step = 1
    * 연결 해제 클릭 > click > 연결된 작업이 있을 때 > 표시줄 숨김, 고른 값·입력값 유지, 해제 안내 > relatedWork = null

### 기존 흐름 테스트 
* 정상 : 유형·분야 선택 → 이름·이메일·메시지 입력 → 다음 > 단계가 순서대로 넘어가고 "n / 4 단계" 문구가 바뀜 > 1 → 2 → 3단계로 이동, 진행 문구 갱신됨 | 통과 |
* 오류 : 빈 칸으로 다음 클릭, 이메일에 `abc` 입력 > 이동이 막히고 수정 방법이 안내됨, 해당 칸에 포커스 > 같은 단계에 머물며 오류 문구 표시, 고치기 시작하면 문구가 사라짐 | 통과 |
* 수정 : 이전 클릭, 확인 화면에서 수정 클릭 후 값 변경 > 입력값이 유지되고 변경한 값이 확인 화면에 반영됨 > 이전 이동 시 값 유지, 바꾼 이름이 확인 화면에 반영됨 | 통과 |
* 완료 : 3단계에서 제출하기 클릭 > 4단계 완료 화면과 완료 문구 표시 | 통과 |
* 초기화 > 새 문의 작성 클릭 > 입력·선택·오류·진행 상태가 모두 처음으로 돌아감 > 모든 칸이 비워지고 1단계로 복귀, 인사말·안내 문구도 처음 문구로 돌아감 | 통과 |

- 5개 시나리오 모두 의도한 대로 동작했다.
