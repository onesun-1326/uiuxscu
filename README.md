## 프로젝트 소개
- 서비스 : SEONWON — 3D 그래픽, 2D 일러스트, AI 영상 포트폴리오
- 사용자 : 작업물을 보러 온 사람 (채용 담당자, 협업 제안자, 동료 창작자)
- 목적 : 어떤 작업을 하는 사람인지 빠르게 파악하고 연락한다
- 핵심 행동 : 관심 분야 작업물 보기 → 문의 남기기

## 사용자 흐름
- 완료 조건 : 3단계에서 제출하면 4단계 완료 화면이 표시된다.
    1. 진입 : 메뉴의 Contact로 이동
    2. 선택 : 문의 유형, 관심 분야
    3. 입력 : 이름, 이메일, 메시지
    4. 확인 : 입력 내용 요약, 항목별 수정
    5. 완료 : 메시지 전송 완료

## 인터렉션 시나리오
- 행동 → 조건 → 반응 → 다음 상태
    * 다음 클릭     > click  > 필수 입력 통과 > 다음 단계 표시, 진행 문구 갱신        > step + 1
    * 다음 클릭     > click  > 필수 입력 누락 > 이동을 막고 오류 안내, 해당 칸에 focus > step 유지
    * 이전 클릭     > click  > 항상           > 이전 단계 표시, 입력값은 그대로       > step - 1
    * 수정 클릭     > click  > 3단계에서      > 해당 단계로 이동                      > step = 1 또는 2
    * 제출 클릭     > submit > 3단계에서      > 완료 화면 표시                        > isComplete = true
    * 새 문의 작성  > click  > 4단계에서      > 입력·선택·오류·진행 상태 초기화       > step = 1

    * 수정 : 이전 클릭, 확인 화면에서 수정 클릭 후 값 변경 > 입력값이 유지되고 변경한 값이 확인 화면에 반영됨 > 이전 이동 시 값 유지, 바꾼 이름이 확인 화면에 반영됨 | 통과 |
    * 완료 : 3단계에서 제출하기 클릭 > 4단계 완료 화면과 완료 문구 표시 | 통과 |
    * 초기화 > 새 문의 작성 클릭 > 입력·선택·오류·진행 상태가 모두 처음으로 돌아감 > 모든 칸이 비워지고 1단계로 복귀, 인사말·안내 문구도 처음 문구로 돌아감 | 통과 |
