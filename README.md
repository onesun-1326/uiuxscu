## 10강 : 메뉴 이동과 목록 탐색

### 추가, 수정한 기능
- 맨 위 메뉴를 `nav` + `ul·li` 구조로 바꾸고 이름을 5개로 정리했다. (소개 / 작업 분야 / 작업물 / 문의하기 / 내 문의)
- 지금 보고 있는 구역의 메뉴에 굵은 글씨 + 밑줄 + 진한 색을 주고 `aria-current="page"`를 붙인다. 다른 메뉴에서는 속성을 뺀다. 메뉴 클릭, 스크롤, 새로고침, 브라우저 뒤로 가기 모두 실제 화면 위치를 기준으로 다시 계산한다.
- 새 구역 '내 문의 내역'을 만들었다. 문의하기에서 제출한 내용(localStorage `seonwon-inquiry-sent`)을 최신순 목록으로 보여 주고, 유형별 필터 버튼 4개(전체 / 협업 문의 / 작업 문의 / 기타)와 건수 안내를 붙였다. 선택한 버튼은 `aria-pressed="true"`이고 글씨·테두리·밑줄도 달라진다.
- 결과가 없는 두 경우를 구분해서 안내한다. (아래 표 참고)
- 모바일(768px 이하)에서는 메뉴를 '메뉴 열기 / 메뉴 닫기' 버튼으로 접고 편다. 화면 문구, 버튼 글자, `aria-expanded`가 함께 바뀌고, 메뉴를 고르면 해당 구역으로 이동하면서 메뉴가 닫힌다. Esc로도 닫힌다.
- 4단계(완료 화면)에 '내 문의 내역 보기' 링크를 추가했다.
- 기존 기능(문의 입력 4단계, 저장, 작업물 분야 체크박스 필터, 작업물 상세 창)은 그대로 동작한다.

### 메뉴 이동 위치
| 메뉴 이름 | 이동하는 곳 (`id`) | 내용 |
|---|---|---|
| 소개 | `#about` | 프로필과 소개 글 |
| 작업 분야 | `#fields` | 3D 그래픽 / 2D 일러스트 / AI 영상 탭 |
| 작업물 | `#works` | 작업물 목록과 분야 필터 |
| 문의하기 | `#contact` | 4단계 문의 폼 |
| 내 문의 | `#history` | 내가 보낸 문의 목록과 유형 필터 |

### 필터 기준 ('내 문의 내역')
| 버튼 | 보여 주는 문의 | 기준 값 |
|---|---|---|
| 전체 | 저장된 문의 전부 | - |
| 협업 문의 | 문의 유형이 '협업 문의'인 것 | `type === "collab"` |
| 작업 문의 | 문의 유형이 '작업 문의'인 것 | `type === "work"` |
| 기타 | 문의 유형이 '기타'인 것 | `type === "etc"` |

목록은 항상 최신순이고, 한 건마다 유형·제출 시각·관심 분야·(있으면) 관련 작업·문의 내용 앞부분(60자까지)을 보여 준다. 이메일과 이름은 목록에 표시하지 않는다.

### 결과가 없을 때 (두 경우를 구분)
| 상황 | 건수 안내 (`role="status"`) | 목록 자리 안내 | 보이는 버튼 |
|---|---|---|---|
| 저장된 문의가 하나도 없음 | 저장된 문의가 없습니다. | 아직 보낸 문의가 없어요. 문의하기에서 첫 문의를 남겨 보세요. | '문의 남기러 가기' 링크 |
| 문의는 있지만 고른 유형에 해당하는 것이 없음 | '기타' 문의는 0건입니다. (전체 3건) | '기타' 유형으로 보낸 문의가 없어요. 다른 유형을 고르거나 전체를 확인해 보세요. | '전체 보기' 버튼 |

### 인터렉션 시나리오 (10강)
- 행동 > 이벤트 > 조건 > 반응 > 다음 상태
    * 메뉴 클릭          > click  > 어느 화면에서나 > 해당 구역으로 이동, 그 메뉴에 `aria-current="page"`        > 모바일이면 메뉴가 닫힘
    * 스크롤·새로고침·뒤로 가기 > scroll / load / hashchange > 어느 화면에서나 > 화면 위쪽 120px 선에 걸린 구역을 현재 위치로 표시 > 메뉴 하나만 현재로 표시
    * '메뉴 열기' 클릭   > click  > 768px 이하        > 메뉴 펼침, 버튼 글자 '메뉴 닫기', `aria-expanded="true"` > 다시 누르거나 Esc, 메뉴 선택 시 닫힘
    * 필터 버튼 클릭     > click  > 내 문의 내역      > 선택 버튼 `aria-pressed="true"`(나머지 false), 목록·건수 안내 갱신 > 결과 0건이면 안내 문구와 '전체 보기'
    * '전체 보기' 클릭   > click  > 필터 결과 0건      > 필터를 '전체'로 되돌림, 첫 필터 버튼에 focus            > 전체 목록 표시
    * 문의 제출 성공     > submit > 3단계              > 목록을 '전체'로 되돌려 새로 그림                       > '내 문의 내역 보기'로 확인

### 직접 확인한 순서 (PC / 모바일 공통)
1. 문의하기에서 협업 문의 1건, 작업 문의 1건을 제출한다.
2. '내 문의 내역 보기' 링크 또는 메뉴 '내 문의'로 이동하고 메뉴에 현재 표시가 옮겨 갔는지 본다.
3. 필터 버튼 4개를 차례로 누르며 목록·건수·`aria-pressed`를 본다.
4. 문의가 없는 유형(예: 기타)을 눌러 0건 안내와 '전체 보기'를 확인한다.
5. 새로고침한 뒤, 브라우저 뒤로 가기를 눌러 현재 메뉴 표시가 화면 위치와 맞는지 본다.
6. 390px 너비에서 '메뉴 열기' → 메뉴 선택 → 이동 후 메뉴가 닫히는지, 가로 스크롤이 없는지 본다.
7. (비우고 시험) 개발자 도구 Application에서 `seonwon-inquiry-sent`를 지운 뒤 새로고침해 '저장된 문의가 없습니다.' 안내를 확인한다.
