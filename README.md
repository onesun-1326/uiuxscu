## 6주차 이후 수정사항

## 확인된 문제
- 학습을 위해 실습하려는 기능을 억지로 삽입하여 실용성이 없었다.
- 때문에 학습기록 보다 본인의 포트폴리오 사이트를 제작으로 변경.

## 수정사항
- 포트폴리오 기록 용으로 변경하여 사이트 이름을 "SEONWON"으로 변경.
- 학습 과목, 학습 로드맵 섹션을 소개란에 결합.
- 작업 분야(3D 환경 / 2D 일러스트 / AI 영상) 탭 3개로 재구성.
- 작업물 8개를 배열 데이터로 만들어 JS로 카드를 생성하도록 수정.
- 카드를 클릭하면 상세 모달이 열리고, 영상은 모달안에서 Vimeo 플레이어로 재생 되도록함.
- CSS를 이용하여 영상 카드에는 재생 아이콘을 추가. (그냥 이미지만 있으니 일러스트와 구분이 안가기 때문.)
